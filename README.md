# 🛒 Projeto E-Commerce DB

> **SENAI Aula** | Repositório dedicado à modelagem, estruturação e gestão de bases de dados relacionais para sistemas de comércio eletrónico.

---

## 📌 Sobre o Projeto
Este repositório armazena os scripts, modelagens e a documentação técnica desenvolvida nas aulas do SENAI, focando na criação de uma arquitetura de dados robusta para um ambiente de *E-Commerce*.

## 🛠️ Tecnologias e Ferramentas
* **Banco de Dados:** MySQL / Relational Database
* **Modelagem:** MER / DER (Modelo Entidade-Relacionamento)
* **Ambiente:** XAMPP / phpMyAdmin / MySQL Workbench

---
*Desenvolvido no âmbito das aulas de desenvolvimento de sistemas do SENAI.*
